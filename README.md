# 部品カウンター MVP

iPad Air 4 の Safari で試すための、独立した静的 Web アプリです。AI・画像解析サーバー・外部 JavaScript ライブラリを使わず、画像処理はブラウザー内の Web Worker で行います。

## iPad で使う

1. このフォルダーの中身を、HTTPS で配信できる静的 Web ホスティングに配置します。初回の読み込み時はインターネット接続が必要です。`index.html` を「ファイル」アプリから直接開くだけでは、Safari のオフライン機能を登録できません。
2. iPad Air 4 の Safari で公開先を開きます。カメラ撮影または「写真を選ぶ」で、トレーを真上から撮った JPEG / PNG を読み込みます。
3. 「画像を解析」を押します。初期設定では画像の端を背景として明暗の向きを判定し、その向きで複数の明るさ境界を縮小画像上で試し、部品領域のまとまり、背景ノイズ、トレー端への広がり、隣接する閾値での安定性を採点して条件を選びます。その後、元解像度で二値化し、孤立した1画素を除去してから、設定した最小面積未満の輪郭を候補から外します。残った輪郭ごとに重心を一つ検出位置として表示します。ねじ山の凹凸で同じ一本に複数のピークができても、別々の部品として数えません。「二値画像」で選ばれた全体二値化の結果、「ノイズ除去後」で最小面積を通過した領域を確認できます。丸い色付きマークが検出位置、黄色が接触や重なりの可能性がある領域です。輪郭候補は部品そのものの個数とは限りません。
4. 形がはっきり写り、他の部品から離れた緑色の検出位置を選び、「基準部品」を押してその位置をタップします。部品の面積、縦横比、角度と周囲との明るさの差を測り、その条件に合わせた局所しきい値で全体を再解析します。基準を変えるときは先に「基準部品を解除」してください。
5. 黄色の場所を拡大して確認します。「＋ 追加」または「− 削除」に切り替えて、画像上をタップすると数量を修正できます。「1つ戻す」で直前の修正を戻せます。
6. 結果を確認して「CSVを書き出す」を押します。CSV には数量、個別位置、検出面積、角度、縦横比、基準面積、手動修正の区別、要確認フラグが入ります。
7. Safari の共有ボタンから「ホーム画面に追加」を選び、「Web アプリとして開く」を有効にして追加します。初回表示後にホーム画面から一度アプリを開き、画面上部に「オフライン利用の準備 OK」と表示されたら、画像選択・解析・設定・CSV 出力はネット接続なしで動作します。

## 解析の調整

- 「部品のおおよその幅」は画像短辺に対する割合です。部品が小さく見落とされる場合は左へ、隣の模様やノイズが多数検出される場合は右へ調整して再解析します。
- 「二値化条件を自動で最適化」を有効にすると、写真の端の明るさから部品と背景の明暗方向を選び、その向きで複数の閾値を試して条件を選びます。手動で調整する場合はチェックを外し、「明るさの境界」と「部品とトレーの明暗」を設定します。
- 設定はブラウザーのローカルストレージに保存されます。写真や解析画像は保存・送信しません。

## 精度について

自動最適化は写真端の画素を背景の明るさとして読み、明暗方向を決めた後、縮小画像で複数の閾値を試します。領域のまとまり、背景ノイズ、画像端への広がり、部品幅に対する細切れ、隣接する閾値での安定性を採点して条件を選びます。これは初期条件を推定するヒューリスティックで、写真ごとの最適値を保証するものではありません。元解像度で選んだ条件を適用し、孤立した1画素を除去した後、設定した最小面積未満の連結領域を除外します。残った領域ごとに重心を一つ候補位置として表示します。局所ピークは形状の警告判定に使いますが、一本のねじにできる複数ピークを数量に加えません。選んだ基準部品の領域面積・角度・縦横比と部品/背景の輝度差をもとに局所しきい値で再解析し、面積や形のずれが大きい候補を要確認として表示します。現段階では、輪郭領域をねじ頭と軸として対応づける処理はありません。一本の部品が複数の輪郭候補に分かれる場合や、複数個が一つの領域につながる場合があります。部品の色、形、光沢、影、トレーとのコントラストで検出結果が変わります。500〜1,000 個の実物画像での精度は未検証で、表示数量を確定値として扱わず、検出位置と黄色の領域を目視確認してください。

操作確認は合成画像を使ったデスクトップブラウザーで行っています。実機 iPad Air 4 の Safari、カメラ起動、実物部品、機内モードでの利用は未確認です。

## ファイル

- `index.html` — 画面
- `app.js` — 操作、撮影画像の読み込み、修正、CSV 出力
- `detector-worker.js` — 端末内画像処理
- `service-worker.js` / `manifest.webmanifest` — オフラインキャッシュとホーム画面追加
