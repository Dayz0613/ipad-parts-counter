# 部品カウンター MVP

iPad Air 4 の Safari で試すための、独立した静的 Web アプリです。AI・画像解析サーバー・外部 JavaScript ライブラリを使わず、画像処理はブラウザー内の Web Worker で行います。

## iPad で使う

1. このフォルダーの中身を、HTTPS で配信できる静的 Web ホスティングに配置します。初回の読み込み時はインターネット接続が必要です。`index.html` を「ファイル」アプリから直接開くだけでは、Safari のオフライン機能を登録できません。
2. iPad Air 4 の Safari で公開先を開きます。カメラ撮影または「写真を選ぶ」で、トレーを真上から撮った JPEG / PNG を読み込みます。
3. 「画像を解析」を押します。初期設定では近傍の背景明るさを推定し、照明むらや広い影の影響を抑えた局所コントラストで二値化します。二値画像の表示では部品幅より十分小さい連結領域をノイズとして取り除きます。膨張・収縮の半径は検出領域数が安定するところから選び、孤立ノイズと設定面積未満の領域を除きます。さらに、設定した部品幅よりかなり小さい領域が複数あり、通常サイズの領域との間に大きな面積差がある場合は、その小領域群をノイズ候補として除きます。似た縦横比と輪郭の詰まり具合を持つ領域が十分にある場合、その領域群の面積中央値を1個分の基準にします。領域数が少なく形状のまとまりを判定できない場合は、最小の有効領域を基準にします。各領域の面積比から数量を推定し、複数個がつながった領域は距離ピークを使って位置候補に分けます。「二値画像」と「膨張収縮後」で処理結果を確認できます。接触や重なり、基準と形が大きく異なる可能性がある位置は黄色で表示します。
4. IC、ネジ、ナット、ワッシャーなど、種類に関係なく、形がはっきり写り他の部品から離れた検出位置を選び、「基準部品」を押してタップします。基準の面積、長短の寸法、縦横比、輪郭の詰まり具合、穴の割合、角度、周囲との明るさの差を記録します。自動二値化中は基準の明暗方向と面積・形状の比較に使い、自動二値化を切ると基準付近の明るさを使った局所しきい値を適用します。基準を変えるときは先に「基準部品を解除」してください。
5. 黄色の場所を拡大して確認します。「＋ 追加」または「− 削除」に切り替えて、画像上をタップすると数量を修正できます。「1つ戻す」で直前の修正を戻せます。
6. 結果を確認して「CSVを書き出す」を押します。CSV には数量、個別位置、検出面積、角度、縦横比、基準面積、手動修正の区別、要確認フラグが入ります。
7. Safari の共有ボタンから「ホーム画面に追加」を選び、「Web アプリとして開く」を有効にして追加します。初回表示後にホーム画面から一度アプリを開き、画面上部に「オフライン利用の準備 OK」と表示されたら、画像選択・解析・設定・CSV 出力はネット接続なしで動作します。

## 解析の調整

- 「部品のおおよその幅」は画像短辺に対する割合です。部品が小さく見落とされる場合は左へ、隣の模様やノイズが多数検出される場合は右へ調整して再解析します。
- 「二値化条件を自動で最適化」を有効にすると、近傍背景との差から照明むらを抑え、閾値前後で形が保たれる度合いから条件を選びます。二値画像の表示には、部品幅に対して小さすぎる領域を除く処理も反映します。手動で調整する場合はチェックを外し、「明るさの境界」と「部品とトレーの明暗」を設定します。
- 設定はブラウザーのローカルストレージに保存されます。写真や解析画像は保存・送信しません。

## 精度について

明確な基準部品を選んだ場合はその面積を使います。基準部品なしで似た形の領域を十分に見つけた場合は、縦横比と輪郭の詰まり具合が近い領域群の面積中央値を使います。まとまりが見つからない場合は最小の有効領域を使います。各連結領域の面積比を切り捨てて数量を推定します。小さなノイズ候補を自動除外する条件は、設定した部品幅より小さな領域が複数あり、残りの領域との間に大きな面積差がある場合に限っています。実際の部品が設定幅より極端に小さく写ると除外される可能性があるため、「膨張収縮後」表示と要確認領域を確認してください。縦横比・輪郭の詰まり具合・穴の割合も形状差の警告に使いますが、形状記述だけで接触・重なりを必ず分離できるわけではありません。表示数量は確定値ではありません。サンプル画像との照合はこれからで、500〜1,000個の精度も未検証です。

操作確認は合成画像を使ったデスクトップブラウザーで行っています。実機 iPad Air 4 の Safari、カメラ起動、実物部品、機内モードでの利用は未確認です。

## ファイル

- `index.html` — 画面
- `app.js` — 操作、撮影画像の読み込み、修正、CSV 出力
- `detector-worker.js` — 端末内画像処理
- `service-worker.js` / `manifest.webmanifest` — オフラインキャッシュとホーム画面追加
